# NEXORA — Smart Automation (MVP)

Application Android (Kotlin + Jetpack Compose + Room + AlarmManager).
Build de l'APK via GitHub Actions : `.github/workflows/android.yml`.
Interface française / arabe (RTL), thème clair / sombre.

Moteur : Déclencheur → Conditions (ET/OU) → Action → Journal.
Protections : arrêt général, limite de répétition (30 s), permissions vérifiées avant exécution.
